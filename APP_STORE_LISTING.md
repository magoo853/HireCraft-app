## App Privacy ("nutrition label") answers

- **Data collected:** User Content (resume text, job codes, performance-review
  text) — collected ONLY when the user runs an AI feature, with consent.
  - Linked to identity: **No** (no accounts, no identifiers).
  - Used for tracking: **No.**
  - Purposes: **App Functionality** only.
- **Data NOT collected:** no contact info, no location, no identifiers, no
  usage analytics, no diagnostics sharing, no financial info (Apple handles
  the subscription).
- Job alerts send only the user's search terms (role/company/location text)
  to public job-board APIs; the resume never leaves the device for alerts.

## Review notes (paste into App Review Information)

HireCraft is a resume-coaching app. No account or login is required; all
features are reachable from the tab bar. On first launch a consent dialog
explains that AI features send the user's resume text to our AI provider
(Google Gemini) — no data is sent before consent, and consent can be
withdrawn in Settings (gear icon, top right).

To evaluate Pro features without purchasing: the web build at the support
URL runs with all features unlocked for demonstration. In the iOS build,
Pro is an auto-renewable subscription ($25/yr, 2-week introductory free
trial) via StoreKit.

Veteran mode (Settings → Mode) enables military job-code translation and
performance-review mining; the six-month military trial will be delivered
as a promotional offer gated by third-party verification (SheerID/ID.me)
in an update — the subscription itself is fully functional at submission.
